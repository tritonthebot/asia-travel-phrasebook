# Asia Travel Phrasebook & Cheat Sheet

Single-file mobile web app for APAC travel.

- 8 countries: Thailand, Japan, Vietnam, Philippines, South Korea, Indonesia, Malaysia, Singapore
- Greetings, Essentials, Dining, Transport, Specialized (e.g. Muay Thai, Vietnamese coffee, jeepney/tricycle) and Numbers 1-10 plus large money amounts
- Tap-to-listen audio, Copy / Favourite / Show
- Live currency converter: open.er-api.com primary, Frankfurter then fawazahmed0 as fallbacks
- Per-country cheat sheets: emergency numbers, tipping, etiquette
- iOS-style UI, country remembered in the browser, empty search links to Google Translate

Open `index.html` or visit the GitHub Pages site.
